# Module N0: Sample Template

N0 is not a functional business module; it is a reference template used to bootstrap new modules. It defines the standard repository communication pattern and illustrates how to use Pydantic contracts for input/output boundary validation.

By establishing a clear convention, N0 ensures that all modules in the distributed system maintain a uniform API surface, regardless of the developer who created them.

---

## Responsibilities

- Provide a standardized directory structure for new modules.
- Demonstrate how to properly export a public API in `__init__.py`.
- Enforce programmatic type-safety at module boundaries using Pydantic V2.
- Define the standard response envelope (`status`, `data`/`normalized`, `metadata`, `error`).

---

## Module Structure

```text
backend/modules/n0_sample/
├── __init__.py          # Re-exports the public API run_sample()
├── sample_logic.py      # Core business logic implementation
└── requirements.txt     # Local module dependencies
```

---

## Public API

```python
from backend.modules.n0_sample import run_sample
from backend.shared.contracts.n0_contracts import N0SampleInput

run_sample(data: Union[N0SampleInput, dict]) -> dict
```

`run_sample()` enforces structural checking at the module's entrance and exit boundaries using Pydantic validation.

---

## Input Contract

The module accepts raw dictionaries matching the schema below or a pre-instantiated `N0SampleInput` model:

```python
class N0SampleInput(BaseModel):
    text: str = Field(default="", description="Sample input text.")
    tags: List[str] = Field(default_factory=list, description="Sample input list of tags.")
```

---

## Output Contract

Every module should return a dictionary conforming to the standard output envelope:

```python
class N0SampleData(BaseModel):
    text: Optional[str] = ""
    tags: List[str] = Field(default_factory=list)

class N0SampleMetadata(BaseModel):
    module: str = "n0_sample"
    latency_ms: float = 0.0

class N0SampleOutput(BaseModel):
    data: N0SampleData = Field(default_factory=N0SampleData)
    metadata: N0SampleMetadata = Field(default_factory=N0SampleMetadata)
```

| Field | Description |
|---|---|
| `data` | The business payload generated by the module. |
| `metadata` | Diagnostic, timing, and observability data for N8 tracing. |

---

## Processing Flow

1. **Receive:** Accepts a raw `dict` payload.
2. **Validate:** Passes payload through `N0SampleInput` to guarantee required fields and default values.
3. **Execute:** Runs internal logic (`sample_logic.py`) using the validated inputs.
4. **Envelope:** Packages the result and timing metadata into `N0SampleOutput`.
5. **Return:** Dumps the Pydantic model to a standard `dict` for the Orchestrator.

---

## Runtime Notes

- Modules should **never** throw unhandled exceptions back to N8. Catch exceptions internally and return an error envelope if necessary.
- Metadata should always include `latency_ms` to facilitate performance benchmarking across the pipeline.
- When creating a new module, simply duplicate this folder, rename the public function, update the contracts, and implement the business logic.
