# N6: Activity Ranking

Ranks activities generated by N5 using semantic similarity between user intent and activity content.

## API
```python
rank_activities(data: dict) -> dict
```

### Input
- `text_k`, `tags_k`: Signal strengths from N1.
- `user_vectors`: Multimodal embeddings (text, aug_text, aug_tags, img_desc).
- `activities`: List of candidates from N5, each with `vectors` and `metadata` (intensity, physical_level, social_level).
- `top_k`: Number of results to return (default: 5).

### Output
- `activities`: Top-K ranked activities with:
  - `score`: Normalized relevance (0.0 - 1.0).
  - `reason`: Natural language explanation (e.g., "phù hợp sở thích", "nhẹ nhàng thư giãn").

## Logic
1. **Semantic Scoring**: Computes weighted cosine similarity between user vectors and activity vectors (text/tag).
2. **Signal Fusion**: Combines scores based on resolved weights from `text_k` and `tags_k`.
3. **Reason Generation**: Analyzes activity levels (`intensity`, `physical_level`, `social_level`) to provide human-readable context in the `reason` field.
4. **Normalization**: Normalizes scores based on the top result to ensure a consistent range.
